# نمایشگر دوربین مداربسته (RTSP)

اپ اندروید (Kotlin + Jetpack Compose + Media3) برای نمایش تصویر دوربین IP.

## امکانات
- ورودی: لینک RTSP، نام کاربری، رمز (ذخیره می‌شوند)
- جستجوی دوربین در شبکهٔ Wi‑Fi: اسکن پورت‌های 554/8554/10554 با تأیید RTSP + کشف ONVIF
- مسیرهای آمادهٔ هایک‌ویژن، داهوا و عمومی
- نمایش با زوم دو‌انگشتی (تا ×10)، جابه‌جایی، دابل‌تپ برای زوم ×3، دکمهٔ 1:1، چرخش افقی، اتصال مجدد
- بافر کم برای تأخیر کم؛ گزینهٔ TCP/UDP

## ساخت APK
**روش ۱ – Android Studio:** پوشه را Open کنید → Build › Build APK(s).

**روش ۲ – GitHub (بدون نصب چیزی):** پوشه را در یک ریپوی GitHub قرار دهید؛
تب Actions → Build APK → فایل APK را از بخش Artifacts دانلود کنید.

## نکات
- گوشی باید به همان روتری وصل باشد که دوربین با کابل به آن متصل است.
- اگر تصویر نیامد: تیک TCP را بردارید یا مسیر فرعی (Sub stream) را امتحان کنید.
- رمز شامل @ یا : مشکلی ندارد؛ خودکار کدگذاری می‌شود.
